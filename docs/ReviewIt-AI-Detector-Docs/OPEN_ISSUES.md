| B1 | Whole-document humanize deferred | `/api/humanize` is out of scope for now (focus: click-to-humanize); to be decided with the supervisor. Known about it: it rewrites every sentence of 4+ words whether flagged or not, passes no neighbour context, returns no per-sentence engine/score, re-joins sentences with single spaces, and is one long blocking request. Its `iterations` and `aggressive` options are accepted but never used. The colleague's frontend (22 Oct) has a "Humanize all" button that calls `/api/humanize-sentence` once per high-AI sentence, one after the other. That is the approach this note recommended (no new backend endpoint, neighbours as context, failures skipped), so `/api/humanize` is still not needed. |
| B2 | Three API implementations | The frontend uses Flask `app.py` (port 5000, built on `service.py`). `aidetector/main.py` is a separate FastAPI app (port 8000) that re-implements the same endpoints with its own copies of the logic (it only shares `pipeline/*`), so the two can drift apart. | B3 | Insecure defaults for any deployment | `app.secret_key = "supersecretkey"` (unused — the app has no sessions), `debug=True` (interactive debugger on errors), `host=0.0.0.0` (reachable from other devices on the network), `CORS(app)` (any website can call the API from a visitor's browser). There is also no upload size limit. Fine on a laptop; not for a shared server or deployment. |
| B4 | No automated tests for the API endpoints | The document pipeline, guard, clean-up and styles have 217 tests (`backend/tests`, run `python -m pytest tests -q`; 21 of them use real papers and run only when the PDFs are in `backend/test_papers/`), but the Flask routes themselves are not tested (the service functions are), and `/api/humanize` and `/api/batch-humanize` have no callers or tests. The models (BERT, Humarin, T5, Gemini) are not exercised by the tests; the routing and the guard are tested with a fake Gemini, and **no rewrite has been run against the paid Gemini key yet**. |
| B5 | *new* — Layout rules are heuristics with known gaps | The upload reader decides from layout. It was checked on 9 real papers (a 28-page paper, a 112-page thesis, a 38-page review, a 7-page journal article, 2 physics papers, a German paper with footnotes and formulas, an AI review with a cover page, a protected file) and on generated PDFs; other layouts can still go wrong. Known gaps: (1) two headings, or a heading and its lead-in sentence, on the same line in the same style (`Research Priorities Critical research gaps requiring attention include:`) stay in one paragraph; a heading on the same line as its text is only split when it has its own font style, or its label style (`a.`, `b.`) is also used on standalone headings in the document and a dash is glued to the last word of the heading; (2) a figure that has no drawn shapes and no table lines can still leak a few words; (3) multi-column papers were not tested (all nine test files are single-column); (4) a paragraph interrupted by a text box in the middle of the page is only re-joined when the part before the box has no sentence end (one test paper keeps 3 such breaks); (5) in equation-heavy papers the text after an equation starts a new paragraph in lower case (about 3–5% of paragraphs in the two physics papers), and a formula line written in plain Latin letters is kept; (6) table and figure captions are only recognised in English (`Table`, `Figure`); (7) a numbered or bulleted list item that is a short label (5 words or fewer) is shown as a heading. **Scanned PDFs are not supported by decision**: the page says so and stops (FB30). |
| B6 | *new* — The detector reads citations as a sign of human text | Measured on real papers by scoring the same sentences with and without citations (`[12]`, `(Smith et al., 2019)`), threshold 0.75: in a citation-dense paper (176 of 452 sentences cited) **184 sentences are flagged with the citations and 380 without** (43% of verdicts change, mean score 0.42 → 0.85); in a thesis (107 of 1104 cited) 996 → 1000; in two lighter papers 28 → 28 and 30 → 38. So the red/green result and the 'AI score now' depend on how many citations a text has, and a rewrite that keeps its citations scores lower partly for that reason. **Decision (2026-10-21): keep citations in the scored text, as now**, because a real detector reads the full text and flagging more sentences would spend extra Gemini calls on cited sentences. To confirm with the supervisor which detector the tool is meant to beat; if it strips citations, revisit. Nothing was changed. |
| B7 | *new* — Direct quotations are not protected | The guard keeps citations, numbers and negation, but text inside quotation marks can still be paraphrased. **Decision: they should be protected** (you, 22 Oct); not built yet. Plan: the guard rejects any rewrite that does not contain every double-quoted passage of 4 or more words word for word (curly and straight quotes count as the same; single quotes are ignored because they cannot be told from apostrophes; short scare quotes such as "so-called" are ignored), a sentence that is only a quotation is skipped, and the splitter keeps a sentence whole while a quote is still open. **Known gap even then:** block quotes in a PDF are usually indented with no quotation marks and cannot be detected reliably. Internal change only; the API does not change. |
| B8 | *new* — The badge can show 1.00 for a rewrite that barely helped | Since the 0.15 margin rule was removed (21 Oct), the lowest safe candidate is used even if it only improves the score a little, so a badge can read `Tier 2 · T5 · 1.00` (0.9996 against 1.0000). The score is correct; it is only rounded to two decimals. A badge `No better rewrite · 0.00` means the sentence is already human on its own (it was red only because of its block of 4); `· 1.00` means it is AI-like and nothing safe scored lower. **Options (undecided):** require a minimum improvement of about 0.02, show three decimals, or reword the 0.00 case ("already human on its own"). Values only: no API key changes. |
| B9 | *new* — Style has a small effect | Only Gemini applies the chosen style, and only through one line of its prompt (the rest of the prompt is the same for all six). Since 22 Oct a non-default style tries Gemini first, but the six styles may still read alike. A stronger per-style prompt (and a measurement of how much the styles differ) would be a separate step; Humarin and T5 cannot apply a style. |
