# Fixed Issues

Last updated 2026-10-26. Issues that were found and fixed on branch `abdullah/humanizer-dev`. IDs are sequential and separate from the ones in `OPEN_ISSUES.md`: `FB` = fixed in the backend, `FF` = fixed in the frontend, `FE` = environment. The `FF` items belong to the first test frontend, which was replaced by the colleague's frontend on 22 Oct (see `PROJECT_WALKTHROUGH.md`). Issues that are still open are in `OPEN_ISSUES.md` (renumbered on 2026-10-20; "old ID" below is the number the issue had before that).

"Checked" says how the fix was confirmed. "Not seen in a browser" means it builds and passes lint, but nobody has looked at it on screen yet.
