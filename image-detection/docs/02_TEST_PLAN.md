# 02 Test plan: validation of AI image detectors

Date: 3 Nov 2026. Prompts: [03_TEST_PROMPTS.md](03_TEST_PROMPTS.md). Results: [04_TEST_RESULTS.md](04_TEST_RESULTS.md).

## Goal

Measure how often each detector (a) calls an AI image AI and (b) wrongly calls a real photo AI, on images that are independent of the models' own benchmarks.

## Test set (100 images)

| Class | Count | Source | Selection |
|---|---|---|---|
| Real | 50 | Open Images (Hugging Face `vikhyatk/openimages-bbox`, test split), Flickr photos from 2018 | 5 per subject; no people; short side 640 px or more; JPEG; subject by CLIP zero-shot (`scripts/fetch_openimages_real.py`) |
| AI | 50 | Generated by us in free tiers | 10 per tool, 5 tools, prompts in `03_TEST_PROMPTS.md` |

- Subjects (10, same for both classes): mountain, coast, forest, street, interior, food, flower, animal, monument, vehicle.
- Real photos predate photorealistic generators (2018). Wikimedia Commons was the first choice but is blocked on this network.

## AI image generation

| Tool | Prompt variant | File prefix |
|---|---|---|
| ChatGPT | 1 | `chatgpt` |
| Gemini | 2 | `gemini` |
| Meta AI | 3 | `metaai` |
| Leonardo.ai | 4 | `leonardo` |
| Recraft | 5 | `recraft` |

Copilot (3 images on the free tier) and Ideogram (not free) were replaced.

Rules:
- New chat for each prompt; paste the prompt exactly; take the first image; no regenerating or editing.
- Download with the tool's download button (no screenshots or conversion); keep visible watermarks.
- Save as `image-detection/test-images/own_test/fake/<tool>__<subject>-<variant>.<ext>`.

## Versions of the 100 images

Every version applies the same processing to real and AI images (`scripts/build_testset.py`).

| Version | Processing | Purpose |
|---|---|---|
| JPEG re-save (main) | RGB, JPEG quality 85, no resize | Removes file format as a clue |
| Original files | As downloaded (PNG, WEBP, JPEG mixed) | Second view |
| Shrunk | Long side 512 px, JPEG quality 90 | Small uploads |
| Screenshot-style | Long side 800 px, PNG | Screenshots |

## Split (fixed, seeded)

| Part | Real | AI | Use |
|---|---|---|---|
| Tuning | 20 | 20 | Choose a cutoff or combination rule |
| Final | 30 | 30 | Report; never used for choosing |

Real photos are split by subject (2 tuning, 3 final per subject). AI images are split by tool and subject (4 tuning, 6 final per tool; each subject is tuned by 2 tools).

## Scoring

- Each model gives a score 0 to 1; AI if the score is at or above the cutoff. Default cutoff 0.5.
- Metrics: real photos wrongly called AI (of 50), AI images caught (of 50), correct overall (of 100), AUC, seconds per image on CPU.
- 95% ranges are Wilson intervals.
- Combination rules: cutoff chosen on the tuning part only, reported on the final part. Rules scored on all 100 at a fixed cutoff are marked as such.
- Only the JPEG re-save version was run for Community Forensics and Bombek1.

## Pipeline

| Step | Script (in `image-detection/scripts/`) |
|---|---|
| Sample real photos | `fetch_openimages_real.py` |
| Build versions and split | `build_testset.py` |
| Score Smaug | `score_smaug.py` |
| Score Community Forensics | `score_commfor.py` (`--selfcheck` reproduces the authors' example) |
| Score Bombek1 | `score_bombek1.py` (`--selfcheck` uses 20 OpenFake images) |
| Report Smaug by split | `analyze_results.py` |

Raw scores: `image-detection/results/*.csv`. Test images are local only (gitignored).

## Limits

- 50 + 50 images: zero false alarms out of 50 still allows a true rate up to about 6%. Suitable for comparing models, not for promising a number to customers.
- Open Images is a common training set; false-alarm rates may look better than they are.
- AI images come from 5 free tiers, one prompt variant per tool.
- Speeds are from a 7.8 GB RAM laptop; Bombek1 was slowed by low free memory.
